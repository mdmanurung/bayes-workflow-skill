## Errata incorporated

| Corrected subject | Official location/topic | Skill treatment |
|---|---|---|
| Posterior predictive definition | Ch8 posterior predictive integral | Use posterior parameter distribution, not a likelihood-only integral. |
| Average causal estimands | Ch7 SATE/PATE normalizing factor | Normalize target weights/averages explicitly. |
| Reverse KL / uncertainty algebra | Variational and normal formulas | Avoid propagating reversed KL or missing square-root errors; no standalone VI recipe is claimed. |
| Movie/rater implementation | Ch16 indexing and translation invariance | Each observation contributes once; both latent coordinates shift together in the invariance. |
| Sleep data/priors | Ch17 N=144, shifted baseline, corrected intercept/slope/scale priors | Corrected quantities used; scales not copied across likelihood transformations. |
| Coronavirus test labels | Ch19 sensitivity/specificity | Label true-positive sensitivity versus true-negative specificity consistently. |
| Dogs priors/history | Ch21 code/history and correct-prior program | Recompute history and use proper stated priors; separate orientation inference listed below. |
| Roaches zeros/K-fold | Ch24 36% zeros and corrected K-fold handling | Do not repeat 64%; do not call loo twice on an already scored result. |
| Golf elementwise multiplication | Ch25 epsilon-vector multiplication | Preserve elementwise intent; validate dimensions. |
| HMM recursion | Ch26 printed recursion notation | Derive/test log-space recursion from implementation; avoid erroneous printed indices. |
| R2D2 residual prior | Ch28 half-Student-t with df=3 | Do not call it half-normal. |
| Planetary observation variance | Ch30 Gaussian variance notation | Distinguish sigma versus sigma-squared. |
