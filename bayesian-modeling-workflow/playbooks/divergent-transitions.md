# Divergent transitions

Read the divergence/energy trees in [computational diagnostics](../references/computational-diagnostics.md).

Capture post-warmup counts by chain, other diagnostics and pairs marked by divergence. Inspect scale/boundary directions in scientific and standardized coordinates. Generate competing hypotheses: weak hierarchy funnel, separation, redundancy, weak nonlinear identification, heavy-tail prior regions or numerical error.

Check prior implications, data information and parameterization equivalence. Non-center weak groups; evaluate centered effects when strongly informed. Use justified priors/support or a revised model only for an identified problem, explaining the statistical change. Consider adapt_delta after geometry diagnosis if mild integration error remains.

Validate with multiple varied plausible starts, divergence locations/counts, R-hat, bulk/tail ESS, energy, target MCSE and predictive checks. If material uncertainty remains, report the fit as provisional. Do not interpret a small divergent fraction as harmless by a universal cutoff or declare success solely because high adapt_delta removed the warning.
