# Expand or revise a model

Read [expansion branches](../references/model-expansion.md). Select the branch implicated by observed inadequacy; simplification or observation repair may be more appropriate than another parameter.

Fill the record before implementation:

```
Observed inadequacy:
Relevance to estimand:
Scientific/statistical explanation:
Competing explanation and discriminating check:
Proposed modification:
Expected consequence:
New identification risk:
Prior changes and implied predictions:
New computational risk:
Validation check:
Result and retain/revise/stop decision:
```

Preserve the current model and execute one meaningful change. Simulate new components, check computation and repeat old PPC plus new targeted checks. Compare only on a matched target when useful. Accept if it addresses the named failure without creating material unsupported interpretation or reliability problems; otherwise diagnose again. Do not follow a fixed ladder to its most complex rung.
